# inventory-api: Sync Lag

## Overview
inventory-api syncs stock levels from warehouse events. Lag appears when the event queue backs up.

## Symptoms
Stock counts stale; sync lag reported on the inventory dashboard.

## Steps
1. Measure event queue depth and consumer throughput.
2. Restart stuck consumers.
3. If a processing bug is present, pause the pipeline at the source.
4. Replay the event stream after the fix.
