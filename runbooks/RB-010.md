# Incident Severity Definitions

## Overview
Defines severity levels. A severity-1 incident is a full customer-facing outage of a core service.

## Symptoms
Criteria for escalating an incident.

## Steps
1. Severity-1: core service (checkout, payments, inventory) fully down or data loss.
2. Severity-2: major degradation, workaround available.
3. Severity-3: non-urgent defect or minor degradation.
4. Declare S1 immediately when customer impact is broad.
