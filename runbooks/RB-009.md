# Deploy Freeze & Change Management

## Overview
Changes to checkout-api, payments-api and inventory-api are frozen during promotional windows unless approved.

## Symptoms
Deploy blocked by the freeze policy; need an exception.

## Steps
1. Check the freeze calendar for the current window.
2. File a change request with risk assessment.
3. Get explicit approval from the change advisory board.
4. Schedule the deploy for the earliest approved slot.
