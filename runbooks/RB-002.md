# checkout-api: Too Many Connections

## Overview
checkout-api uses Postgres with a shared connection pool. 'Too many connections' errors typically follow pool exhaustion.

## Symptoms
ERROR: too many connections; checkout-api 503s; idle connections maxed.

## Steps
1. Check pool utilization and count of open Postgres connections.
2. Increase pgbouncer max_client_conn and restart lookup.
3. Look for a runaway migration holding locks or a long-running query.
4. If a migration is the cause, pause it; kill blocked sessions.
