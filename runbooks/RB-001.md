# checkout-api: High CPU

## Overview
checkout-api handles order checkout traffic. High CPU usually means a sudden traffic spike or an inefficient hot path.

## Symptoms
Sustained CPU >80% on checkout-api pods; latency p95 climbs; checkout timeouts.

## Steps
1. Check CPU dashboard and recent deploys in the last 2 hours.
2. Confirm there is no stuck checkout loop (look for repeated order mutations).
3. Check autoscaler target; scale up if traffic is legitimately high.
4. Profile the hot path (perf) before making code changes.
