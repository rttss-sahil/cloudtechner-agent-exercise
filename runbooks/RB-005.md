# checkout-api: Safe Rollback

## Overview
checkout-api ships via blue-green deploys. Rolls back are safe when DB migrations are backward-compatible.

## Symptoms
Regression found after a checkout-api deploy; need to revert quickly.

## Steps
1. Verify the migration in the target release is backward-compatible.
2. Flip the canary/blue-green switch back to the previous build.
3. Watch error rate and latency for 10 minutes.
4. If schema changes are incompatible, open a data-fix ticket instead of reverting.
