# payments-api: High CPU

## Overview
payments-api authorizes and settles payments. High CPU is usually a retry storm from downstream providers or a hot code path.

## Symptoms
Sustained CPU >80% on payments-api pods; settlement lag grows; provider timeouts.

## Steps
1. Check CPU dashboard and downstream provider latencies.
2. Inspect retry loops on failed authorizations.
3. Verify settlement batch sizes; they can explode under spike.
4. Profile the hot path (perf) before changing code.
