# Incident Postmortem 2026-08-10 (checkout-api outage)

## Overview
On 2026-08-10 checkout-api was down for 47 minutes. Root cause was a deploy that shipped an incompatible DB migration; the fix was a rollback plus a data-fix ticket to reconcile dropped orders.

## Symptoms
checkout-api 503s; orders stuck in 'processing'; payment links failed.

## Steps
1. Deploy 2026-08-10 09:12 pushed an incompatible migration.
2. 09:18 error rates rose; incident declared at 09:21 (S1).
3. 09:41 rollback executed; service restored 09:59.
4. Follow-up: backward-compatibility gate added to the deploy pipeline; orders reconciled via data-fix queue.
